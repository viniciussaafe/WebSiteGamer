💻 Apresentação do Meu Website Gamer

🚀 Desenvolvi um Moderno Website Gamer com HTML, CSS e JS 🌟<br><br>
Eu transformei minha criatividade em realidade e construí um Website Gamer visualmente impressionante, utilizando o front-end com HTML, CSS e JavaScript, e um sistema de autenticação robusto!<br>
O grande destaque é o sistema de Login e Cadastro completo que desenvolvi, utilizando o Supabase como plataforma Backend as a Service (BaaS) para gerenciar o banco de dados e a autenticação.<br>
O fluxo de segurança e acesso é simples e eficiente:<br>
    Tela de Cadastro (Sign-Up): O usuário cria sua conta inserindo um e-mail e uma senha segura (que não deve esquecer).<br>
    Confirmação de E-mail: Para garantir a segurança e a validade do cadastro, o usuário deve confirmar a criação da conta diretamente no seu e-mail.<br>
    Tela de Login (Sign-In): Após a confirmação, basta usar o botão de Login para inserir as credenciais e acessar a área restrita do site.<br>
No design, foquei em uma UI minimalista e moderna inspirada nos padrões Awwwards, utilizando:<br>
    Estética Neon e Tema Escuro: Para a atmosfera gamer perfeita.<br>
    Animações de Rolagem e Efeitos Parallax: Para uma experiência do usuário (UX) cativante.<br>
    Layout Responsivo: Desenvolvido com CSS Grid e Flexbox, garantindo que o site funcione perfeitamente em qualquer dispositivo.<br>
Explore a combinação de código criativo e tecnologias modernas que usei para criar esta experiência web.<br>
